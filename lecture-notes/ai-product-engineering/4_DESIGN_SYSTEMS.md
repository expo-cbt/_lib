A moodboard is a visual collection of inspiration used to define the look, feel, and style of a design project before designing.
It typically includes:
Color palettes
Typography
Images and photography
UI inspirations
Icons and illustrations
Textures and patterns
Brand references
Keywords describing the desired mood (e.g., modern, minimalist, playful, premium)
Purpose: Align stakeholders on the project's visual direction and maintain consistency throughout the design process.

A design system framework is the structure used to organize and build a design system. A common framework includes:
1. Foundations – Colors, typography, spacing, grids, icons, elevation, motion.
2. Design Tokens – Reusable variables that define the foundations.
3. Components – Buttons, inputs, cards, modals, navigation, etc.
4. Patterns – Common combinations of components for user tasks (forms, dashboards, checkout).
5. Templates – Reusable page layouts.
6. Guidelines – Accessibility, content, interaction, and brand rules.
7. Documentation & Governance – Standards for maintaining, updating, and using the design system.
